## Como manter
- Só entra aqui o que o dono confirmou. Conversa, rascunho e relatório são referência, não regra.
- Mudou uma regra, decisão ou padrão? Atualize a linha no documento certo, na mesma entrega.
- Algo deixou de valer? Mova para "Itens obsoletos" com o valor atual.
- Mantenha cada documento curto (uma tela ou duas). Detalhe fica no arquivo de origem, com o caminho.

## Para usar no Projeto do Claude (claude.ai)
Suba estes 7 arquivos e o `CLAUDE.md` na base de conhecimento do Projeto. Nas instruções do Projeto, cole o conteúdo do `CLAUDE.md`. Não suba históricos de conversa.
