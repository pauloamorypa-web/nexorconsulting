# Logomarca Nexor em vetor

Arquivos vetoriais da logomarca oficial, vetorizados a partir da arte original sem alterar o desenho. Use estes arquivos para gráfica, fachada, adesivo, bordado e brindes.

| Arquivo | Uso |
| --- | --- |
| `nexor-logo-principal-fundo-escuro` (.svg/.pdf) | Versão preferencial, com o fundo navy |
| `nexor-logo-principal-transparente.svg` | Sobre fundos escuros |
| `nexor-logo-principal-positiva` (.svg/.pdf) | Fundos claros (letras em navy) |
| `nexor-logo-principal-branca.svg` / `-preta.svg` | Uma cor: gravação, carimbo, serigrafia |
| `nexor-logo-compacta-*` | Espaços pequenos, assinatura, rodapé |
| `nexor-icone-*` | Ícone X com ✓: perfil, aplicativo, favicon, selo |

Cores: Navy #010524 · Branco Gelo #EBF1F9 · Ciano #00E1FB · Azul Consulting #0084F5 · Azul Elétrico #0058FA.
Os valores CMYK estão no manual da marca; peça uma prova de cor à gráfica antes de imprimir em quantidade.
